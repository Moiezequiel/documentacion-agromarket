    Services

    AuthService.js

    Servicios de autenticación

    Función

    Provee funciones para:

    • Login de usuario
    • Registro de nuevo usuario

    Variables

    Variable Valor
    API_URL import.meta.env.VITE_API_BASE_URL

    Funciones

    loginService(username, password)

    Realiza login de usuario.

    Parámetro Tipo Descripción
    username string Nombre de usuario
    password string Contraseña del usuario

    Retorna: Objeto con token JWT y datos del usuario.

    Errores: Lanza excepción con mensaje si las credenciales son inválidas.

    Endpoint:
    POST /auth/login
    Content-Type: application/json

    registerService(username, email, address, phone, password, lat, lng)

    Registra un nuevo usuario.

    Parámetro Tipo Descripción
    username string Nombre de usuario
    email string Correo electrónico
    address string Dirección del usuario
    phone string Teléfono
    password string Contraseña
    lat float Latitud
    lng float Longitud

    Retorna: Objeto con mensaje de registro.

    Errores: Lanza excepción con mensaje si falla el registro.

    Endpoint:
    POST /auth/register
    Content-Type: application/json

    CartService.js

    Servicios de carrito de compras

    Función

    Provee funciones para:

    • Obtener carrito del usuario
    • Agregar productos al carrito
    • Eliminar productos del carrito
    • Actualizar cantidades en el carrito

    Variables

    Variable Valor
    API_URL import.meta.env.VITE_API_BASE_URL

    Funciones

    getCart()

    Obtiene el carrito actual del usuario.

    Retorna: Objeto con estructura { items: [...] } o null si ocurre error.

    Errores: Muestra error en consola, no lanza excepción.

    Endpoint:
    GET /cart/

    addToCart(productId, quantity)

    Agrega un producto al carrito.

    Parámetro Tipo Descripción
    productId string ID del producto
    quantity number Cantidad a agregar

    Retorna: Respuesta del servidor.
    Errores: Lanza excepción en caso de error.

    Endpoint:
    POST /cart/add

    removeFromCart(productId)

    Elimina un producto del carrito.

    Parámetro Tipo Descripción
    productId string ID del producto a eliminar

    Retorna: Respuesta del servidor.
    Errores: Lanza excepción en caso de error.

    Endpoint:
    DELETE /cart/remove

    updateCart(items)

    Actualiza el carrito completo con nuevas cantidades.

    Parámetro Tipo Descripción
    items Array Array de objetos { productId, quantity }

    Retorna: Respuesta del servidor.
    Errores: Lanza excepción en caso de error.

    Endpoint:
    PATCH /cart/update

    UserService.js

    Servicios de perfil de usuario

    Función

    Provee funciones para:

    • Obtener la información del perfil del usuario autenticado
    • Actualizar la información del perfil del usuario

    Variables

    Variable Valor
    API_URL import.meta.env.VITE_API_BASE_URL

    Funciones

    getUserInfo()

    Obtiene la información actual del usuario autenticado.

    Retorna: Objeto con los datos del perfil.

    Errores:

    • Lanza excepción si no hay token
    • Lanza excepción si la respuesta no es válida (response.ok === false)
    • Muestra error en consola

    Endpoint:
    GET /profile/info

    updateUser(updatedData)

    Actualiza los datos del usuario.

    Parámetro Tipo Descripción
    updatedData Object Objeto con los campos a actualizar

    Retorna: Respuesta del servidor con los datos actualizados.

    Errores:

    • Lanza excepción si no hay token
    • Lanza excepción si la respuesta no es válida
    • Muestra error en consola

    Endpoint:
    PATCH /profile/update

    categoryService.js

    Servicios de categorías y unidades de medida

    Función

    Provee funciones para:

    • Obtener la lista de categorías disponibles
    • Obtener la lista de unidades de medida

    Variables

    Variable Valor
    API_URL import.meta.env.VITE_API_BASE_URL

    Funciones

    getCategories()

    Obtiene todas las categorías disponibles en el sistema.

    Retorna: Array de objetos categoría.

    Errores: Lanza excepción si ocurre error de red.

    Endpoint:
    GET /data/categories

    getMeasureUnits()

    Obtiene todas las unidades de medida.

    Retorna: Array de objetos unidad de medida.

    Errores: Lanza excepción si ocurre error de red.

    Endpoint:
    GET /data/measureUnits

    geolocationService.js

    Servicio de geolocalización inversa

    Función

    Convierte coordenadas geográficas (lat, lng) en una dirección en texto (reverse geocoding), usando el servicio público de OpenStreetMap (Nominatim).

    Función

    geolocationService(lat, lng)
    Parámetro Tipo Descripción
    lat number Latitud
    lng number Longitud

    Retorna:
    String con la dirección completa (display_name) devuelta por Nominatim.

    Errores:
    Lanza excepción si falla la consulta o la respuesta no es OK.

    Endpoint:
    GET https://nominatim.openstreetmap.org/reverse

    productService.js

    Servicios de gestión de productos

    Función

    Provee funciones para:

    • Obtener lista de productos
    • Obtener detalles de un producto
    • Crear un nuevo producto
    • Obtener productos publicados por el usuario actual
    • Actualizar un producto

    Variables

    Variable Valor
    API_URL import.meta.env.VITE_API_BASE_URL

    Funciones

    getProducts()

    Obtiene todos los productos publicados en la plataforma.

    Retorna: Array de productos.

    Errores: Lanza excepción si ocurre error de red.

    Endpoint:
    GET /products/all

    getProductById(id)

    Obtiene los detalles de un producto específico por ID.

    Parámetro Tipo Descripción
    id string ID del producto

    Retorna: Objeto con los datos del producto.

    Errores: Lanza excepción si ocurre error.

    Endpoint:
    GET /products/{id}

    createProductService(productData, token)

    Crea un nuevo producto.

    Parámetro Tipo Descripción
    productData Object Datos del producto (name, desc, img...)
    token string JWT token (Bearer)

    Retorna: Objeto con datos del producto creado.

    Errores: Lanza excepción si ocurre error.
