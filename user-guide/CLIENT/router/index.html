    Router

    AppRouter.jsx

    Definición de rutas de la aplicación (cliente)

    Función

    Gestiona las rutas de navegación utilizando react-router-dom.
    Define rutas públicas y rutas privadas protegidas por rol de usuario.

    Estructura de rutas

    Ruta Componente Acceso
    / Login Pública
    /register Register Pública
    /home Home Privada, rol: user
    /cart Cart Privada, rol: user
    /seller/home SellerHome Privada, rol: seller
    /profile UserProfile Privada, roles: user, seller

    Composición

    Elemento Descripción
    <BrowserRouter> Envoltura de router principal
    <Routes> Define las rutas y sus componentes
    <Route> Define cada ruta individual
    <PrivateRoute> Componente que protege rutas en base a rol (HOC)
    <Layout> Componente contenedor de las rutas privadas

    Comportamiento

    • Las rutas públicas (/, /register) no requieren autenticación.
    • Las rutas privadas requieren autenticación y validación de rol:
    • Se usa el componente <PrivateRoute> con la prop roleRequired.
    • El layout general (Layout.jsx) envuelve las rutas privadas, proporcionando UI consistente (navbar, sidebar, etc).

    Librerías utilizadas

    • react-router-dom: BrowserRouter, Routes, Route

    PrivateRoute.jsx

    Componente para proteger rutas privadas

    Función

    Envuelve rutas que requieren autenticación y controla el acceso según el rol del usuario.

    Comportamiento

    • Si el usuario NO está autenticado → redirige a / (login).
    • Si el token JWT no es válido → redirige a /.
    • Si el rol del usuario NO está en los roleRequired → redirige a /home.
    • Si el rol es válido → muestra los children (componente protegido).

    Props

    Prop Tipo Descripción
    children ReactNode Componente que se mostrará si autorizado
    roleRequired string / array Rol requerido o lista de roles permitidos

    Lógica

    • Obtiene user desde el AuthContext (hook useAuth()).
    • Decodifica el token JWT (guardado en localStorage).
    • Extrae el role del token para validar acceso.

    Librerías utilizadas

    • react-router-dom: Navigate
    • jwt-decode
    • Custom hook: useAuth()
