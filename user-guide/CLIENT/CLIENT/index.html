    Cliente Web - AgroMarket

    El cliente web de AgroMarket es una aplicación desarrollada en React.js como parte del stack MERN.
    Permite a los usuarios:

    • Explorar productos agrícolas disponibles
    • Visualizar rutas y ubicaciones en el mapa
    • Iniciar sesión, registrarse y gestionar su perfil
    • Interactuar con productores

    Estructura de Carpetas

    src/

        ├── assets/ → Imágenes y recursos estáticos

    ├── components/ → Componentes UI reutilizables

    ├── context/ → Contextos de React (manejo de auth)

    ├── features/ → Funcionalidades agrupadas (auth, products, profile)

    ├── hooks/ → Custom Hooks (por ejemplo, autenticación)

    ├── pages/ → Páginas principales del sitio

    ├── router/ → Rutas de navegación (React Router)

    ├── services/ → Servicios API (auth, productos, geolocalización)

    ├── index.css → Estilos generales

    └── main.jsx → Entry point de la app

    Páginas Principales

    Página Archivo Descripción
    Home pages/Home.jsx Página principal de productos
    Login pages/Login.jsx Inicio de sesión
    Register pages/Register.jsx Registro de nuevos usuarios
    Perfil de usuario features/profile/Userprofile.jsx Página de perfil

    Componentes Destacados

    Componente Archivo Función
    Navbar components/Navbar.jsx Barra de navegación superior
    Sidebar components/Sidebar.jsx Barra lateral de navegación
    ProductCard components/ProductCard.jsx Tarjeta de producto individual
    Pagination components/Pagination.jsx Paginación de productos
    LocationModal components/LocationModal.jsx Modal para selección de ubicación
    Layout components/Layout.jsx Componente de layout general

    Servicios API

    Servicio Archivo Descripción
    AuthService services/AuthService.js Manejo de autenticación (login, registro)
    UserService services/UserService.js Servicios relacionados al usuario
    ProductService services/productService.js Servicios para consulta de productos
    geolocationService services/geolocationService.js Servicios de geolocalización / rutas

    Navegación (Routing)

    Las rutas principales se definen en:

    • router/AppRouter.jsx → rutas públicas y privadas
    • router/PrivateRoute.jsx → componente de protección de rutas

    Contexto

    El contexto principal de la aplicación se maneja en:

    • context/AuthContext.jsx → contexto global de autenticación

    Ejecución en local

    Entrar en la carpeta del cliente

    cd AGROMARKET_CLIENTs

    Instalar dependencias

    npm install

    Ejecutar en modo desarrollo

    npm run dev
